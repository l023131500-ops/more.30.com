# חיבור המערכת הקולית — ימות המשיח

המאגר מדבר עם ימות המשיח בשני כיוונים. המערכת הקולית פונה לאתר בכל שיחה
ומקבלת הוראות מה להשמיע, והאתר יודע לבנות את השלוחות בעצמו דרך ה-API של ימות.

---

## מה צריך להכין

1. מספר מערכת בימות המשיח, לדוגמה `0773137770`.
2. מפתח API מהגדרות המערכת, או לחלופין סיסמת המערכת.
3. שלוחה פנויה שתשמש כשלוחת הבסיס של האיגוד, לדוגמה `1`.

---

## הגדרה במסך הניהול

נכנסים לכתובת `/admin`, לשונית **חיבורים והגדרות**, ובחלק של ימות המשיח:

| שדה | הסבר |
|---|---|
| מספר המערכת | מספר הקו בימות המשיח |
| מפתח API | המפתח מהגדרות המערכת. עדיף על סיסמה |
| סיסמת המערכת | בשימוש רק אם לא הוגדר מפתח |
| שלוחת הבסיס | השלוחה שתחתיה ייבנו כל התפריטים |

לוחצים **שמירה**, ואז **בניית השלוחות**.

המערכת בודקת את המפתח מול ימות, ורק אם הוא תקין כותבת את קובצי ה-`ext.ini`.

---

## מה נבנה

תחת שלוחת הבסיס נוצר תפריט ראשי, ומתחתיו חמש שלוחות:

| שלוחה | תפקיד | מסלול באתר |
|---|---|---|
| 1 | חיפוש שיעור לפי עיר, לפי נושא, או השיעורים הקרובים | `/api/yemot/search` |
| 2 | עדכון שיעור קיים, לפי מספר הטלפון של המתקשר | `/api/yemot/update` |
| 3 | הצטרפות כמגיד שיעור | `/api/yemot/maggid` |
| 4 | פתיחת שיעור תורה חדש | `/api/yemot/host` |
| 5 | חיפוש בדיבור חופשי | `/api/yemot/agent` |

### תוכן ext.ini של שלוחת API

```ini
type=api
api_url=https://<כתובת האתר>/api/yemot/search
api_url_post_data=ApiCallId,ApiPhone,ApiExtension,ApiDID,ApiEnterID
api_max_call_length=600
```

### תוכן ext.ini של תפריט הבסיס

```ini
type=menu
timeout=10
enter_id_list_message=t-ברוכים הבאים לאיגוד השיעורים, מחברים בין לומדים ומלמדים. לשלוחת חיפוש שיעור הקישו 1. ...
first_time_playing=yes
```

## מהלך השיחה בכל שלוחה

### שלוחה 1, חיפוש

```
תפריט: לפי עיר / לפי נושא / השיעורים הקרובים בכל הארץ
  לפי עיר   -> רשימת ערים ממוספרת, תשע בכל עמוד, אפס להמשך
  לפי נושא  -> רשימת נושאים ממוספרת
  ואז       -> הקראת עד חמישה שיעורים קרובים
```

### שלוחה 2, עדכון

הזיהוי לפי מספר הטלפון של המתקשר, כפי שנשמר בפרטי הקשר של השיעור.

```
בחירת השיעור -> בחירת היום -> שעה חדשה בארבע ספרות -> שמירה מיידית
```

לדוגמה, לשעה שמונה ורבע בערב מקישים `2015`.

### שלוחות 3 ו-4, הצטרפות

השלוחות אוספות את הפרטים החיוניים בהקשות, שומרות פנייה במאגר,
ומודיעות שנציג יחזור להשלמת השאלון. השאלון המלא נמצא באתר.

### שלוחה 5, סוכן קולי

מקבלת משפט חופשי, מפרשת אותו ומקריאה את השיעורים המתאימים.
אם הוגדר מפתח של Claude במסך ההגדרות, הפירוש מזהה עיר, נושא ושם רב מתוך
המשפט. בלי מפתח, הסוכן נופל לחיפוש לפי מילות מפתח ועדיין עובד.

## בטיחות

הקוד מכיל שומר סף שחוסם כל כתיבה מחוץ לשלוחת הבסיס:

```ts
assertInRoot(`ivr2:/${root}/1/ext.ini`, root);   // עובר
assertInRoot('ivr2:/7/ext.ini', '1');            // נחסם
```

בנוסף, אין בקוד שום פעולת מחיקה מול ימות המשיח. הבנייה כותבת קבצים בלבד.

---

## התאמת פרוטוקול

סדר הפרמטרים של הפקודה `read` משתנה מעט בין גרסאות של ימות המשיח.
ברירות המחדל כאן:

```
read=t-<טקסט>=<שם המשתנה>,<ניסיונות>,<מינימום ספרות>,<מקסימום>,<שניות המתנה>,
     <סוג קלט>,<אישור>,<חסימת כוכבית>,<חסימת אפס>,<תו החלפה>,<ספרות מותרות>,<ריק מותר>
```

אם הקלט אינו נקלט כמצופה, משנים את הפונקציה `read` בקובץ `lib/yemot.ts`.
זה המקום היחיד שבו הפרוטוקול נבנה, ושינוי שם משפיע על כל השלוחות.

---

## בדיקה ידנית

```bash
curl "https://<כתובת האתר>/api/yemot/search"
curl "https://<כתובת האתר>/api/yemot/search?mode=3"
curl -X POST "https://<כתובת האתר>/api/yemot/agent" -d "text=דף יומי בבני ברק"
```

התשובה היא טקסט בפרוטוקול של ימות, לדוגמה:

```
id_list_message=t-חיפוש שיעור תורה&read=t-לחיפוש לפי עיר הקישו 1=mode,3,1,1,7,number,no,no,no,,,no
```
