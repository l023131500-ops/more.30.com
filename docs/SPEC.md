# מסמך אפיון — מערכת ניהול מכירות משקפיים
**"אופטיקה לכל כיס" בשיתוף ארגון "בקלות"**

גרסה 1.0 · מסמך אפיון פונקציונלי וטכני מלא

---

## 1. תיאור כללי

מערכת פנימית לניהול מכירות משקפיים המתקיימות באולמות בשכונות ברחבי הארץ.
המערכת מנהלת את מחזור החיים המלא של כל מכירה: תכנון בלוח שנה, הגדרת המיקום,
ניהול ההוצאות, רישום הלקוחות והמשקפיים, מעקב תשלומים ומסירות, חישוב רווחיות,
דיוור טלפוני (צינתוקים) ללקוחות, ודוחות.

**קהל היעד:** צוות ניהול פנימי (משתמש בודד או צוות קטן).
**שפה:** עברית מלאה, ממשק RTL.
**עקרון מנחה:** מסכים תפעוליים, ללא טקסטי הסבר מיותרים.

## 2. ארכיטקטורה

| רכיב | מימוש |

## 3. מודל הנתונים

### 3.1 `settings` — הגדרות

```js
{
  orgName, subtitle, currency,
  weekend: { friday: bool, saturday: bool },
  holidayRules: {                      // אילו סוגי מועדים חוסמים מכירה
    yomtov, cholhamoed, erev, fastMajor, fastMinor,
    purim, memorial, national, minor, roshchodesh
  },
  customerColumns: [                   // הגדרת עמודות טבלת הלקוחות
    { key, label, type, width, visible, options[], locked }
  ],
  tableConfig: {
    topTitle,                          // כותרת מעל הטבלה
    sideHeader,                        // כותרת עמודת הצד
    sideHeaderField,                   // index | firstName | lastName | phone
    showTotals
  },
  defaultCostRows: [{ label, amount }], // סעיפי הוצאה שנוצרים בכל מכירה
  taskTemplates: [string],
  yemot: {
    systemNumber, apiKey, callerId, tzintukTimeout,
    mode: 'proxy'|'direct', proxyUrl, baseUrl,
    messageFile, ttsText, rsvpEnabled, rsvpExtension
  }
}
```

**סוגי עמודה (`type`):** `text` · `tel` · `email` · `money` · `check` · `select`

### 3.2 `sale` — מכירה

```js
{
  id, date: 'YYYY-MM-DD', slot: 1|2|3,      // slot = מכירה מס' N באותו יום
  city, hallName, neighborhood, street, houseNumber,
  startTime, endTime,
  status: 'planned'|'confirmed'|'done'|'cancelled',
  separation,                                // הפרדה מלאה / לנשים / לגברים / מעורב
  contactName, contactPhone,
  costs:     [{ id, label, amount, paymentMethod, paidTo, status, dueDate, note }],
  customers: [{ id, firstName, lastName, phone, email, city, neighborhood,
                glassesType, rightEye, leftEye, price, paid, paidAmount,
                paymentMethod, delivered, notes, ...שדות מותאמים }],
  tasks:     [{ id, title, assignee, dueDate, done, note }],
  notes:     [{ id, text, createdAt }],
  ads:       [{ id, name, type, size, uploadedAt }],   // הקובץ עצמו ב-IndexedDB
  campaigns: [{ id, type, typeLabel, sentAt, ok, targets[] }],
  createdAt
}
```

### 3.3 שאר האוספים

| אוסף | תיאור |
|---|---|
| `dayFlags` | `{ 'YYYY-MM-DD': { blocked: true, note } }` — חסימה ידנית של יום (אדום) |

| `campaigns` | כל הצינתוקים/הודעות שנשלחו, כולל סטטוס לכל נמען |

## 4. מסך 1 — דשבורד מרכזי (לוח שנה)

### 4.1 תצוגה

* לוח חודשי מלא, **עברי־לועזי**: בכל תא מוצג מספר היום הלועזי + התאריך העברי בגימטריה.
* כותרת החודש: שם החודש הלועזי + שנה, ומתחתיו טווח החודשים העבריים
  (לדוגמה: "אוגוסט 2026 / אב – אלול תשפ״ו").
* ניווט: הקודם / החודש / הבא, וכן בורר חודש ושנה. **מעבר החודשים אוטומטי ורציף.**
* שורת מחוונים חודשית: מספר מכירות, לקוחות, הכנסות, הוצאות, רווח, יתרה לגבייה.

### 4.2 קוד הצבעים

| צבע | משמעות |
|---|---|
| 🟩 **ירוק** | היום פנוי למכירה |
| 🟦 **כחול** | יש מכירה ביום זה — **מוצג בתא מיקום המכירה** (עיר · שכונה, אולם, רחוב ומספר) |
| 🟥 **אדום** | היום סומן ידנית כלא פנוי למכירה |
| ⬜ **אפור** | יום שישי, שבת, וימי חג — ללא מכירות |

היום הנוכחי מסומן במסגרת כתומה.

### 4.3 חגים

מועדי ישראל מחושבים אוטומטית מהלוח העברי, ומסווגים לקטגוריות שניתן להפעיל/לכבות בהגדרות:

| קטגוריה | דוגמאות | חוסם כברירת מחדל |
|---|---|---|
| יום טוב | ר״ה, יו״כ, סוכות א׳, שמח״ת, פסח א׳, שביעי ש״פ, שבועות | ✔ |
| חול המועד | חוה״מ סוכות ופסח, הושענא רבה | ✔ |
| ערב חג | ערב ר״ה, ערב יו״כ, ערב סוכות, ערב פסח, ערב שבועות | ✘ |
| צום מרכזי | יום כיפור, תשעה באב | ✔ |
| תענית | צום גדליה, י׳ בטבת, תענית אסתר, י״ז בתמוז | ✘ |
| פורים | פורים, שושן פורים, פורים קטן | ✔ |
| יום זיכרון | יום השואה, יום הזיכרון | ✘ |
| יום לאומי | יום העצמאות | ✘ |
| מועד | חנוכה, ט״ו בשבט, ל״ג בעומר, יום ירושלים | ✘ |
| ראש חודש | כל ראשי החודשים | ✘ |

כללי הדחייה ממומשים: צום שחל בשבת נדחה ליום ראשון; תענית אסתר שחלה בשבת מוקדמת לחמישי;
יום העצמאות ויום השואה נדחים לפי הכללים המקובלים.

### 4.4 אינטראקציה

| פעולה | תוצאה |
|---|---|
| לחיצה על יום ריק | חלון: פתיחת מכירה / סימון כלא פנוי / הערה ליום |
| לחיצה על יום עם מכירה אחת | כניסה ישירה לדשבורד המכירה |
| לחיצה על יום עם 2+ מכירות | חלון בחירה בין המכירות + כפתור "מכירה נוספת" |
| **כפתור `+` בתא** | פתיחת **מכירה נוספת** באותו יום (מכירה שנייה, שלישית וכו׳) |
| לחיצה ימנית | תפריט מהיר של היום |

בימים עם יותר ממכירה אחת מוצג בתא תג "N מכירות", וכל מכירה מופיעה כשורה נפרדת
עם המיקום שלה — כך שבמסך הראשי רואים שיש 2 מכירות והיכן הן ממוקמות.

מתחת ללוח: טבלת **מכירות קרובות** (6 הבאות) עם קיצור דרך לפתיחה.

## 5. מסך 2 — דשבורד יום המכירה

### 5.1 שורת מחוונים עליונה
לקוחות · סה״כ מכירות · שולם · נותר לתשלום · הוצאות · רווח (+% רווחיות) · נמסרו משקפיים.

### 5.2 ניהול המכירה — פרטי המיקום
עיר האולם · שם האולם · שכונה · רחוב · מספר · תאריך (ניתן לעדכון) · שעת התחלה · שעת סיום ·
סטטוס · אופי המכירה (הפרדה מלאה / לנשים / לגברים / מעורב / לפי שעות) · איש קשר + טלפון.

### 5.3 הוצאות המכירה ותשלומים
טבלה שנפתחת עם 3 שורות ברירת מחדל (ניתנות לשינוי בהגדרות):
1. **מחיר האולם**
2. **מודעה במקומון**
3. **הדפסת והדבקת מודעות**

לכל שורה: **סכום** · **אופן התשלום** (מזומן / אשראי / העברה בנקאית / צ׳ק / ביט / טרם שולם) ·
**למי מעבירים** · **סטטוס** (טרם שולם / שולם / שולם חלקית) · תאריך יעד · הערה.
**ניתן להוסיף שורות ללא הגבלה.** בתחתית: סה״כ הוצאות, מתוכן שולמו, ויתרה.

### 5.4 לוח מחוונים — רווחיות
* גרף הכנסות מול הוצאות (הכנסות / נגבה / הוצאות / רווח).
* גרף פילוח אמצעי תשלום.
* נקודת איזון (כמה לקוחות נדרשים לכיסוי ההוצאות), הוצאה ממוצעת ללקוח, רווח ממוצע ללקוח.

### 5.5 טבלת הלקוחות (סגנון אקסל)
עמודות ברירת מחדל: שם פרטי · שם משפחה · טלפון · דוא״ל · עיר · שכונה · סוג משקפיים ·
עין ימין · עין שמאל · מחיר · שולם ✓ · סכום ששולם · אמצעי תשלום · נמסר ✓ · הערות.

* עריכה ישירה בתא, שמירה אוטומטית.
* עמודת צד (ברירת מחדל: מספר רץ) — ניתנת להחלפה לשם משפחה / טלפון וכו׳.
* שורת סיכום בתחתית: סה״כ מחירים, סה״כ ששולם, כמה שילמו, כמה נמסרו.
* סימון "שולם" ממלא אוטומטית את סכום התשלום.
* **תיבות סימון לבחירת קבוצת לקוחות לשליחת צינתוק.**

**כפתורי הטבלה:** הוספת לקוח · ייבוא מאקסל (עם מיפוי עמודות) · **הורדת אקסל** · הורדת CSV ·
**שליחת צינתוק** · **⚙ הגדרות טבלה**.

### 5.6 הגדרות טבלת הלקוחות (⚙)
* **כותרת עליונה** — הטקסט שמעל הטבלה.
* **כותרת הצד** — שם העמודה הראשונה, ומה יוצג בה.
* הצגה/הסתרה של כל עמודה, שינוי שם, שינוי סוג, שינוי רוחב, שינוי סדר (▲▼).
* הוספת עמודות חדשות ומחיקת עמודות (למעט עמודות נדרשות לחישובים).
* הפעלה/כיבוי של שורת הסיכומים.

### 5.7 מודעת המכירה
העלאת קובץ (תמונה / PDF, ריבוי קבצים) · תצוגה מקדימה · **צפייה** בחלון חדש · **הורדה** · מחיקה.

### 5.8 משימות המכירה
רשימת משימות עם אחראי ותאריך יעד, סימון ביצוע, מונה משימות פתוחות,
ותבניות מהירות בלחיצה אחת (אופטומטריסט, להוסיף משקפי X, הבאת ציוד, תיאום עם ועד השכונה,
תליית מודעות, סידור האולם — ניתנות לעריכה בהגדרות).

### 5.9 הערות המכירה
הערות חופשיות עם חותמת זמן — לדוגמה "מכירה בהפרדה מלאה", "הכניסה מרחוב צדדי".

### 5.10 ניווט בין מכירות באותו יום
כשקיימות מספר מכירות באותו יום מוצג תג "מכירה N מתוך M" וכפתורי מעבר מהיר ביניהן,
וכן כפתור "+ מכירה נוספת ביום זה".

## 6. מסך 3 — מכירות קודמות ומאגר לקוחות

* מאחד את כל הלקוחות מכל המכירות במערכת **יחד עם** רשומות שיובאו מאקסל.
* **סינון:** חיפוש חופשי · עיר · שכונה (מתעדכנת לפי העיר) · סוג משקפיים ·
  טווח תאריכים · שולם/לא שולם · נמסר/לא נמסר · מקור הרשומה.
* מחוונים: לקוחות בסינון · טלפונים ייחודיים · סה״כ מכירות · שולם · ערים · שכונות.
* **ייבוא נתוני מכירות קודמות מאקסל** עם מיפוי עמודות אינטראקטיבי וזיהוי אוטומטי של כותרות.
* **סימון קבוצה → שליחת צינתוק לפי אזור.**
* ייצוא כל התוצאות המסוננות לאקסל.
* טבלת היסטוריית מכירות עם רווח ורווחיות לכל מכירה.

## 7. מסך 4 — צינתוקים והודעות (ימות המשיח)

### 7.1 שליחה
נשלח משני מקומות: ממסך יום המכירה (לכל הלקוחות או למסומנים) וממסך מכירות קודמות (לפי אזור).

**סוגי שליחה:**
| סוג | תיאור |
|---|---|
| צינתוק | חיוג קצר ללא מענה (`RunTzintuk`) |
| קמפיין השמעת הודעה | השמעת קובץ/טקסט (`RunCampaign`), עם SMS נלווה אופציונלי |
| SMS | הודעת טקסט (`SendSms`) |
| **אישור הגעה** | תשתית מוכנה — קמפיין שמבקש הקשה 1=מגיע / 2=לא מגיע |

לכל שליחה: בחירת callerId, משך צינתוק, קובץ הודעה, תוכן SMS,
ו**מצב "הרצת בדיקה"** שמתעד את השליחה בלי לשלוח בפועל.
מספרי טלפון עוברים נרמול אוטומטי (972+ → 0, הסרת תווים, סינון כפילויות ומספרים לא תקינים).

### 7.2 מעקב
מסך נפרד המציג את כל הקמפיינים, ולכל קמפיין את רשימת הנמענים ו**האם שמעו את ההודעה**,
סטטוס השיחה, ואישור הגעה. ניתן לעדכן ידנית או לרענן אוטומטית מהמערכת.
ייצוא לאקסל של כל קמפיין ושל הדוח המרוכז.

### 7.3 הגדרות החיבור
מסך ההגדרות מכיל: **מספר המערכת** · **מפתח ה-API** · מספר מזוהה יוצא · משך צינתוק ·
אופן החיבור (שרת ביניים / ישיר) · כתובת ה-API · קובץ ההודעה · טקסט להקראה ·
הפעלת אישורי הגעה + שלוחת IVR · **כפתור "שמירה ובדיקת חיבור"**.

פירוט מלא: [`YEMOT_API.md`](YEMOT_API.md).

## 8. מסך 5 — דוחות

בחירת תקופה (מתאריך / עד תאריך, או החודש / השנה / הכל). כל דוח ניתן ל**הורדה כאקסל** ולהדפסה.

| דוח | תוכן |
|---|---|
| סיכום כללי | כל המחוונים, גרף הכנסות חודשי, 10 המכירות הרווחיות |
| מכירות | שורה לכל מכירה: תאריך לועזי+עברי, יום, מיקום מלא, סטטוס, לקוחות, הכנסות, נגבה, יתרה, הוצאות, רווח |
| רווחיות | רווח, שיעור רווח, רווח ללקוח, נקודת איזון + גרף |
| ערים ושכונות | פילוח גיאוגרפי מלא + גרף הכנסות לפי עיר |
