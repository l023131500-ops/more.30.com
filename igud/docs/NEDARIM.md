# חיבור נדרים פלוס

שני כיוונים: קליטת טפסים שמולאו בעמדות, ופרסום השיעורים חזרה למערכת.

---

## כיוון ראשון: קליטה מנדרים פלוס

### הכתובת שמוסרים לנדרים פלוס

```
POST https://<כתובת האתר>/api/nedarim/callback
```

### אימות

במסך הניהול, לשונית **חיבורים והגדרות**, ממלאים **סוד ה-callback**.
נדרים פלוס שולחים אותו בכל פנייה, באחת משתי דרכים:

- בכותרת `x-igud-secret`
- בשדה `secret` בגוף הפנייה

אם השדה נשאר ריק במסך הניהול, הכתובת מקבלת פניות בלי אימות. לא מומלץ.

### בדיקת חיים

```
GET https://<כתובת האתר>/api/nedarim/callback?ping=1
```

מחזירה אישור בלי לכתוב נתונים.

שמות השדות זהים לשמות בטופס 4320 של נדרים פלוס, כולל תיבות הימים
`Day1` עד `Day9` והשעות `time1` עד `time9`.

סדר תיבות הימים קבוע:

| תיבה | יום | עמודת שעה בייצוא לאקסל |
|---|---|---|
| Day1 | יום ראשון | AC |
| Day2 | יום שני | AD |
| Day3 | יום שלישי | AE |
| Day4 | יום רביעי | AF |
| Day5 | יום חמישי | AG |
| Day6 | יום שישי | AH |
| Day7 | ליל שבת | AI |
| Day8 | שבת | AJ |
| Day9 | מוצאי שבת | AK |

### הטפסים הנתמכים

| FormId | תפקיד | לאן נכנס |
|---|---|---|
| 4320 | עדכון שיעור לפרסום | `igud_lessons`, בסטטוס ממתין לאישור |
| 4063 | בקשה למגיד שיעור | `igud_requests`, סוג `open_lesson` |
| 4018 | רישום כמגיד שיעור | `igud_requests`, סוג `maggid` |
| 4357 | הרשמה לקבלת עדכונים | `igud_subscribers` |

כל רשומה נכנסת לתור האישור. שום דבר אינו מתפרסם באתר בלי אישור ידני.

## כיוון שני: פרסום אל נדרים פלוס

```
POST https://<כתובת האתר>/api/nedarim/push?since=2026-01-01&limit=200
```

דורש הרשאת מנהל. פרטי החיבור נלקחים ממסך ההגדרות: מספר מוסד, ApiValid ומפתח API.

הגוף שנשלח:

```json
{
  "Mosad": "<מספר מוסד>",
  "ApiValid": "<מפתח>",
  "Action": "IgudHashiurimSync",
  "Lessons": [
    {
      "ExternalId": "…",
      "Number": 42,
      "Title": "דף יומי",
      "Rabbi": "הרב ישראל כהן",
      "Location": "בית הכנסת אור החיים",
      "City": "ירושלים",
      "Address": "הרב שך 12, הר נוף, ירושלים",
      "Topics": "דף יומי, הלכה בעיון",
      "Schedule": "יום ראשון 20:30 | יום שני 20:30",
      "Broadcast": "live",
      "Url": "https://<כתובת האתר>/lesson/…"
    }
  ]
}
```

כתובת היעד נקבעת במשתנה הסביבה `NEDARIM_ENDPOINT`. ברירת המחדל היא
`https://www.matara.pro/nedarimplus/Reports/ApiSet.aspx`.
אם נדרים פלוס מספקים כתובת אחרת או שם פעולה אחר, משנים את המשתנה
ואת השדה `Action` בקובץ `app/api/nedarim/push/route.ts`.

## ייבוא מקובץ אקסל

מי שמעדיף לא לחבר API יכול לייצא מנדרים פלוס לקובץ xlsx ולהעלות אותו
במסך הניהול, לשונית **ייבוא וייצוא**. המערכת מזהה את מספר הטופס לבד,
מציגה כמה רשומות נמצאו, ומאפשרת לייבא לתור האישור או לפרסם מיד
רשומות שעברו בדיקת איכות.

הייבוא אידמפוטנטי: רשומה שכבר נקלטה לפי המזהה שלה תעודכן ולא תיווצר פעמיים.
