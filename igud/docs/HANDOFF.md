## המשך פיתוח: מה כדאי להוסיף

לפי סדר התועלת:

1. **התראות** לרב ולמרכז כששיעור אושר או נדחה, בדוא"ל או בהודעה קולית.
2. **חיפוש לפי קרבה גיאוגרפית**. השדות `geo_lat` ו-`geo_lng` כבר קיימים
   בטבלאות אך אינם ממולאים. הוספת גיאוקודינג בעת האישור תפתח חיפוש
   "שיעורים לידי".
3. **זמני היום** מתוך לוח עברי, כדי לתמוך בשיעורים שנקבעים לפי מנחה
   ושקיעה. יש כבר מימוש לוח עברי ב-`lib/hebcal.js`.
4. **עמוד שבועי להדפסה** לכל בית כנסת, לתלייה על לוח המודעות.
5. **סטטיסטיקות** למנהל: כמה נכנסים, מה מחפשים, אילו ערים חסרות שיעורים.

## דברים שכדאי לדעת לפני שנוגעים בקוד

- **הבנייה חייבת לעבור**: `cd igud && npm run build`. אין להסתמך רק על
  `npm run dev`, כי בדיקות הטיפוסים רצות רק בבנייה.
- **המרת טפסים** יושבת כולה ב-`lib/nedarim.js`. אותו קובץ משמש גם את
  הדפדפן וגם את סקריפטי המסוף. שינוי שם משפיע על שני המסלולים.
- **פרוטוקול ימות המשיח** נבנה במקום אחד בלבד, בפונקציה `read`
  שבקובץ `lib/yemot.ts`. אם ההקשות לא נקלטות, זה המקום להתאים.
- **אין למחוק כלום מימות המשיח**. הקוד כותב קבצים בלבד, במכוון,
  והכתיבה חסומה מחוץ לשלוחת הבסיס.
- **נתונים אישיים** אינם נשמרים בריפוזיטורי. קובצי האקסל המקוריים
  לא הועלו, וחולצה מהם רק הטקסונומיה.
