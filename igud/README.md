# איגוד השיעורים

מאגר ארצי של זמני שיעורי תורה. מחברים בין לומדים ומלמדים.

האתר מציג את השיעורים הקרובים בכל הארץ, מאפשר חיפוש לפי רב, נושא, עיר ובית כנסת,
וקולט שיעורים חדשים משלושה ערוצים: האתר, המערכת הקולית ועמדות נדרים פלוס.
כל שיעור עובר אישור לפני שהוא מתפרסם.

---

## מה יש כאן

| שכבה | מימוש |
|---|---|
| אתר | Next.js 15, App Router, TypeScript, Tailwind 4, עברית מלאה ו-RTL |
| מסד נתונים | Supabase Postgres, טבלאות בתחילית `igud_` |
| הזדהות | Supabase Auth, דוא"ל או מספר טלפון |
| אחסון | דלי `igud-media` ללוגואים ולתמונות |
| מערכת קולית | ימות המשיח, חמש שלוחות API |
| נדרים פלוס | כתובת callback לקליטה, ו-API יוצא לפרסום |
| סוכן קולי | Claude, עם נפילה חיננית לחיפוש מילות מפתח |

## הרצה מקומית

```bash
cd igud
npm install
cp .env.example .env.local     # וממלאים את הערכים
npm run dev
```

האתר עולה על http://localhost:3000

### משתני סביבה

| משתנה | חובה | תפקיד |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | לא | כתובת פרויקט Supabase. בלעדיו נעשה שימוש בפרויקט ברירת המחדל |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | לא | מפתח פרסום. הוא נשלח לכל דפדפן ממילא, וההגנה נשענת על RLS |
| `NEXT_PUBLIC_SITE_URL` | מומלץ | כתובת האתר, לצורך תגיות שיתוף וקישורים בתיעוד |
| `IGUD_SERVICE_EMAIL` | לכתיבה מהשרת | חשבון שירות המוגדר כמנהל, למסלולי המערכת הקולית ונדרים פלוס |
| `IGUD_SERVICE_PASSWORD` | לכתיבה מהשרת | סיסמת חשבון השירות |
| `SUPABASE_SERVICE_ROLE_KEY` | חלופה | מפתח שירות ישיר, במקום חשבון השירות |
| `ANTHROPIC_API_KEY` | רשות | לסוכן הקולי. אפשר גם למלא במסך הניהול |

בלי הגדרת גישת שרת, האתר הציבורי, הטפסים, האזור האישי ומסך הניהול עובדים
במלואם. מה שלא יעבוד הוא מסלולי המערכת הקולית וקליטת נדרים פלוס, והם
יחזירו הודעת שגיאה ברורה.

## מבנה התיקיות

```
igud/
  app/                   דפי האתר ומסלולי ה-API
    page.tsx             הדשבורד
    lesson/[id]/         דף שיעור מלא
    rabbi/[id]/          כל שיעורי הרב
    venue/[id]/          כל השיעורים במקום
    search/ centers/ rabbis/
    add/                 אשף הוספת שיעור, טופס 4320
    join/                הצטרפות: פתיחת שיעור (4063) ומגיד שיעור (4018)
    p/[token]/           קישור אישי לרב או למרכז
    portal/              אזור אישי
    admin/               מערכת ניהול
    api/                 יומן, מערכת קולית, נדרים פלוס, ממשק ציבורי
  components/            רכיבי הממשק
  lib/                   נתונים, לוח עברי, xlsx, ימות המשיח, נדרים פלוס
  data/taxonomy.json     רשימות הבחירה, גיבוי מקומי
  scripts/               ייבוא קובצי אקסל מהמסוף
  docs/                  תיעוד מפורט
```

## סקריפטים

```bash
npm run dev                  # פיתוח
npm run build                # בנייה לייצור
npm run start                # הרצת הבנייה

# ייבוא ייצוא של טפסי נדרים פלוס ישירות למסד
node scripts/import-nedarim.mjs <קובץ.xlsx> [--publish] [--dry]

# המרה להצהרות SQL, כשאין גישת רשת ישירה למסד
node scripts/to-sql.mjs <קובץ.xlsx> --publish > seed.sql
```

הייבוא זמין גם ממסך הניהול, בלשונית ייבוא וייצוא, בלי צורך במסוף.

## אבטחה בקצרה

- קורא אנונימי מקבל רק שיעורים שאושרו לפרסום, ורק עמודות שנועדו לפרסום.
  דוא"ל, אסימונים אישיים והערות ניהול אינם נחשפים.
- הגשת טפסים עוברת בפונקציות מסד אטומיות ומאומתות. אין הרשאת כתיבה ישירה
  לאף טבלה מהדפדפן האנונימי.
- רב או מרכז תורה רואים ומעדכנים רק את השיעורים שלהם, לפי RLS.
- כתיבה למערכת הקולית מוגבלת לשלוחת הבסיס בלבד, ואין בקוד שום פעולת מחיקה.
- כתובת ה-callback של נדרים פלוס מאומתת מול סוד שנקבע במסך הניהול.
