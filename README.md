# 👓 אופטיקה לכל כיס — מערכת ניהול מכירות משקפיים

מערכת פנימית לניהול מכירות משקפיים באולמות בשכונות ברחבי הארץ.
**עברית מלאה · RTL · לוח שנה עברי־לועזי · ללא תלויות חיצוניות.**

## 🚀 המערכת חיה ופעילה

### **https://optika-sales.vercel.app**

מוכנה לשימוש מיידי. כל פוש לענף `claude/glasses-sales-management-system-rgejc6`
מתעדכן אוטומטית באתר.

---

## הפעלה מקומית

```bash
git clone https://github.com/l023131500-ops/more.30.com.git
cd more.30.com
python3 -m http.server 8080      # או:  npx serve .
```

פתחו: **http://localhost:8080**

> אפשר גם לפתוח את `index.html` ישירות, אך מומלץ להריץ דרך שרת מקומי
> כדי שמודולי ה-JavaScript ייטענו כראוי.
>
> **גרסת קובץ יחיד:** `dist/index.html` — קובץ אחד שכולל הכול,
> נפתח בדאבל-קליק ללא שרת ובלי התקנה. לבנייה מחדש: `node build.mjs`.

**להתנסות מהירה:** הגדרות → נתוני הדגמה → "טעינת נתוני הדגמה".

## מה יש במערכת

### 📅 לוח שנה — הדשבורד המרכזי
לוח חודשי **עברי־לועזי** עם מעבר חודשים אוטומטי.
🟩 פנוי למכירה · 🟦 יש מכירה (עם המיקום בתא) · 🟥 לא פנוי · ⬜ שישי/שבת/חג.
חגי ישראל מחושבים אוטומטית מהלוח העברי, כולל כללי הדחייה.
כפתור `+` בכל יום פותח **מכירה נוספת** — ימים עם 2 מכירות מציגים את שתיהן ואת מיקומן.

### 🛒 דשבורד יום מכירה
פרטי המיקום (עיר, אולם, שכונה, רחוב, מספר, תאריך, שעות, אופי המכירה) ·
**הוצאות** עם אופן תשלום ולמי מעבירים, שורות ללא הגבלה ·
**לוח מחוונים לרווחיות** עם נקודת איזון ·
**טבלת לקוחות בסגנון אקסל** עם סיכומים חיים ·
**מודעה** — העלאה, צפייה והורדה · **משימות** · **הערות** · **שליחת צינתוק**.

### 📚 מכירות קודמות
מאגר לקוחות מאוחד עם **סינון לפי ערים ושכונות**, ייבוא אקסל של נתוני עבר,
וסימון קבוצה לשליחת צינתוק לפי אזור.

### 📞 צינתוקים — ימות המשיח
צינתוק · קמפיין הודעה · SMS · תשתית אישורי הגעה.
מסך מעקב שמציג **מי שמע את ההודעה** ומי אישר הגעה.

### 📊 דוחות
10 דוחות: סיכום · מכירות · רווחיות · ערים ושכונות · תשלומים וגבייה ·
מסירות · סוגי משקפיים · הוצאות · חודשי · צינתוקים. **כולם עם ייצוא לאקסל.**

### ⚙️ הגדרות
כללי החסימה בלוח · **הגדרות טבלת האקסל** (עמודות, כותרת עליונה, כותרת צד) ·
סעיפי הוצאה קבועים · תבניות משימות · חיבור לימות המשיח · גיבוי ושחזור.

## מבנה הפרויקט

```
index.html              מעטפת היישום
assets/styles.css       מערכת עיצוב RTL
src/
  app.js                ניתוב ואתחול
  hebcal.js             לוח עברי (מאומת מול ICU על 25,000+ ימים)
  holidays.js           מועדי ישראל וכללי חסימה
  store.js              נתונים (IndexedDB) וסיכומים כספיים
  xlsx.js               קריאה/כתיבה של xlsx ו-csv
  yemot.js              לקוח API של ימות המשיח
  ui.js                 רכיבי ממשק
  views/                המסכים
api/yemot.js            שרת ביניים (Serverless)
docs/                   תיעוד
```
