# נתוני מקור

`taxonomy.json` — כל רשימות הבחירה של הטפסים, שחולצו מקבצי הרשומות של
טפסי נדרים פלוס 4320 (עדכון שיעור), 4063 (בקשת מגיד שיעור),
4018 (רישום כמגיד שיעור) ו-4357 (חיפוש שיעור).

**קבצי האקסל המקוריים אינם נשמרים בריפוזיטורי הזה.**
הם מכילים נתונים אישיים של אנשים אמיתיים — שמות מלאים, טלפונים,
כתובות דוא״ל ומספרי תעודת זהות — והריפוזיטורי ציבורי.
מהקבצים חולצו רק רשימות הבחירה (טקסונומיה), ללא כל פרט מזהה.

לטעינת נתונים אמיתיים למערכת יש להשתמש במסך **ניהול → ייבוא מאקסל**,
שמייבא אל מסד הנתונים הפרטי ולא אל הקוד.
