# חיזוקים קצרים → ימות המשיח

העלאת ארכיון ההקלטות מאתר "חיזוקים קצרים" אל שלוחה במערכת הקולית של
ימות המשיח, מסודר לפי נושאים.

## מה הכלי עושה

1. **שולף** את כל ההקלטות ממסד הנתונים של האתר — כולל הכותרת הערוכה,
   שדה הפרשה/מועד, אורך ההקלטה וקישור לקובץ השמע.
2. **מסנן** הקלטות פסולות: קצרות מ-30 שניות, הודעות טכניות למאזינים,
   וכל רשומה בלי קובץ שמע.
3. **מסווג** כל הקלטה לשלוחה: מועד → פרשה → נושא, לפי סדר עדיפות זה.
4. **מפריד** את החיזוק השבועי (מוצאי שבת) לשלוחה נפרדת.
5. **מעלה** את הקבצים ומגדיר את השלוחות.

## מבנה השלוחות

```
5           חיזוקים קצרים
├── 0       החיזוק השבועי — מוצאי שבת
├── 1       פרשות השבוע        → 1-5 חומשים → פרשה
├── 2       מועדים וזמנים      → 1-12 לפי סדר השנה
├── 3       אמונה, ביטחון והשגחה
├── 4       תפילה, ברכות ולימוד תורה
├── 5       מידות, שמחה והכרת הטוב
├── 6       בין אדם לחברו ושמירת הלשון
├── 7       שלום בית, חינוך וצדקה
├── 8       תשובה, יצר הרע והתמודדות
└── 9       משלים, סיפורי צדיקים ועבודת האדם
```

שם כל קובץ הוא **נושא ההקלטה**, לפי הכותרת הערוכה שבאתר.
תיקייה עם יותר מ-60 הקלטות מתפצלת אוטומטית ל"חלק א׳ / חלק ב׳".

## בטיחות

הכלי **אינו יכול** לגעת בשלוחות אחרות:

* לכל כתיבה עוברת דרך `assertInRoot()`, שדוחה כל נתיב שאינו בתוך
  `ivr2:/5`. נתיב מחוץ לשלוחה מפיל את הריצה.
* **אין בקוד שום פעולת מחיקה.** לא של קובץ, לא של שלוחה.
* `npm run verify` מדפיס את תוכן שלוחה 5 לפני שנוגעים בה, ומריץ את בדיקת
  הבטיחות על כל נתיב בתוכנית.

## הפעלה

```bash
cd chizukim
cp .env.example .env      # ומלאו את הפרטים
npm run plan              # בונה תוכנית — לא נוגע בימות המשיח
npm run verify            # בודק חיבור ומדפיס את מצב שלוחה 5
npm run pilot             # מעלה 3 קבצים בלבד — להאזנה ובדיקה בטלפון
npm run upload            # ההעלאה המלאה
npm run status            # מה הועלה, מה נכשל
```

`npm run plan` כותב ל-`out/`:

| קובץ | תוכן |
|---|---|
| `tree.txt` | עץ השלוחות המלא עם מספר ההקלטות בכל אחת |
| `skipped.txt` | כל הקלטה שדולגה, עם הסיבה |
| `plan.json` | התוכנית המלאה — כל קובץ והנתיב שאליו הוא הולך |

**עברו על `tree.txt` ועל `skipped.txt` לפני `npm run upload`.**

## הרצה חוזרת

`out/state.json` רושם כל קובץ שהועלה בהצלחה. הרצה חוזרת של `npm run upload`
מדלגת על מה שכבר עלה ומשלימה רק את החסר — אפשר לעצור באמצע ולהמשיך.
כישלון בקובץ בודד אינו עוצר את הריצה; הוא נרשם ומופיע ב-`npm run status`.

## מה עוד לא אומת

תבניות ה-`ext.ini` שב-`src/templates.mjs` נכתבו לפי מבנה ההגדרות המקובל,
אך **טרם נבדקו מול המערכת החיה**. זו בדיוק מטרת `npm run pilot`: להעלות
שלוש הקלטות, להתקשר לשלוחה, ולוודא שהתפריט וההשמעה עובדים — לפני שמעלים
את הכול. אם נדרש תיקון, הוא כולו בקובץ `templates.mjs`.
